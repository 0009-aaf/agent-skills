**主体难度**（[VERIFIED] run1 数值 + run2 视觉双重确认）：黑白人像失败率 50%（人脸最敏感，人像走摄影工艺或配具体描述）＞ 彩色花 33% ＞ 日出剪影 17% ＞ 灯塔/浪/城市 8%。


> 每种工艺是真实存在的制作流程，有材料、工具、工序、痕迹。工艺卡里的每个视觉特征必须能追溯到一道工序。
> 生成前**必读所选工艺的整张卡**：把「工艺语言」片段注入提示词第 5 模块，返检时按「质检项」核对。
> 收录条件：工艺必须真实存在，有明确的材料、工具、工序、痕迹。不收录"霓虹赛博""孟菲斯"这类美术风格——它们是构图基因或色彩规则，不配当工艺卡。

## 通用规则（所有工艺共同）

- 写实锚区（原照片的主体区）保持真实形态与光线，工艺只作用于工艺区（背景 / 氛围）。
- 空间关系、姿态、光线方向由保护清单锁定，任何工艺不得破坏。
- 三层分层对所有工艺生效，工艺只改变"如何表现层级"，不取消层级。
- 保真旋钮不许超过本卡保真上限；抽象旋钮不许超过本卡抽象倾向。越界换工艺，不硬调。
- 输出宽高比默认跟随源图逻辑。

## 1. woodcut — 木刻版画

- **材料**：梨木 / 椴木版、油性墨（黑或单色）、手工纸。
- **工具与工序**：起稿 → 墨稿反拓上版 → 刻刀铲除空白 → 滚墨 → 压印。粗犷刀痕来自刻刀直接切削木纤维。
- **工艺痕迹**：刀痕方向与断口、平行刀纹、刻刀铲空的纸白、油墨不均（浓淡、蹭版）、边缘偶尔崩裂的木渣。
- **保真上限**：剪影级。保主体轮廓、姿态、大块明暗；不保纹理与微结构。
- **抽象倾向**：默认 2；范围 1-3。
- **色彩规则**：黑白单色，或一枚单色（墨绿 / 赭红 / 靛蓝）代替黑。禁止多色。
- **文字与排版**：可刻文字（刀刻字，≤5 英文词 / ≤8 汉字）；默认 no-text。
- **构图基因**：大块黑承担主体，纸白负空间承担安静；刀痕方向跟随主体姿态；前景刀法粗、背景刀法疏。
- **质检项**：刀痕方向是否跟随姿态？大块黑是否承担主体？是否只有一种墨色？纸白负空间是否在？有没有柔边渐变混进来？
- **工艺参考图**：`assets/craft-samples/woodcut.jpg`
- **适用限制**：渐变天空场景（黄昏紫粉 / 暮色 / 霞光）易残留柔边渐变混入，定向修正一次后仍难完全消除（[VERIFIED] 复现测试实测：重跑后质检仍 fail，见 `tests/repro-test/`）；此类场景可接受轻微渐变，或换银盐 / 水墨。

**工艺语言片段（可注入第 5 模块）**：
```
木刻版画：硬边雕刻，粗犷刀痕与断口，白色高光由刀刻出；主体靠大块黑色剪影保持识别；前景刀法粗、背景刀法疏；油墨不均的印刷颗粒；纸白负空间承担安静。
```

## 2. ukiyo-e — 浮世绘多色套版

- **材料**：多块樱木版、水性颜料（靛蓝 / 赭 / 墨绿 / 朱）、和纸。
- **工具与工序**：勾线稿 → 每色一块版 → 依次套印。每块版单独上色、对位、压印，套印必然错位。
- **工艺痕迹**：清晰轮廓线 + 平面色块、套印错位（边缘露出的浅色）、木纹与版压痕、和纸纤维。
- **保真上限**：剪影级偏上。保主体轮廓与色彩关系，不保微结构。
- **抽象倾向**：默认 2；范围 2-3。
- **色彩规则**：低饱和传统色域（靛 / 赭 / 墨绿 / 朱 / 和纸米白），2-4 色；禁止荧光。
- **文字与排版**：可竖排短句或印章式红字（≤8 汉字）；默认 no-text。
- **构图基因**：前景大块剪影框景、中景主体、背景以纹样节奏表现（水纹 / 云纹 / 山纹）；对角线优先。
- **质检项**：套印错位是否克制（有但不大）？轮廓线是否清晰？色数是否在 2-4？有没有西式透视渐变混进来？
- **适用限制**：**有机复杂形状主体（花等）易被替换为无关元素**（视觉实测：花朵主体丢失、出现源图没有的编织物/花盆）；对细节主体有'再诠释'倾向，保真要求高时慎用。
- **工艺参考图**：`assets/craft-samples/ukiyo-e.jpg`

**工艺语言片段**：
```
浮世绘多色套版：清晰轮廓线 + 平面色块，2-4 色低饱和传统色域（靛/赭/墨绿/朱/和纸米白）；轻微套印错位与木纹；前景大块剪影框景、背景水云山纹样节奏；对角线构图。
```

## 3. watercolor — 水彩

- **材料**：冷压水彩纸、透明水彩颜料、貂毛 / 尼龙笔、清水。
- **工具与工序**：湿纸铺色 → 干笔收形 → 逐层罩染 → 留白。水痕来自水在纸上的干燥速度。
- **工艺痕迹**：湿润色块、水痕边缘（干燥沉积）、纸纹颗粒、留白即高光、轻微颜料沉淀。
- **保真上限**：高。可保大部分细节，纹理与微结构会被水洗淡。
- **抽象倾向**：默认 1；范围 0-2（水彩偏保留氛围）。
- **色彩规则**：保持照片自然色相，水洗降饱和；相邻色自然晕染；禁止撞色与荧光。
- **文字与排版**：可钢笔 / 铅笔手写小字或旅行手账批注（≤8 汉字 / ≤5 英文词）；默认 no-text。
- **构图基因**：主体中景湿画法最实，前景少量轻快笔触，背景大块晕染承接天空 / 水面；边角留白；画框感。
- **质检项**：水痕是否自然（来自干燥而非描边）？主体是否最实？有没有出现厚重油画感或全部硬边？
- **工艺参考图**：`assets/craft-samples/watercolor.jpg`

**工艺语言片段**：
```
水彩：透明水彩与湿润色块，纸纹与留白即高光；主体中景湿画法最实，背景大块晕染承接氛围；相邻色自然晕染，水洗降饱和；可见水彩纸颗粒；边角留白。
```

## 4. torn-paper — 撕纸拼贴

- **材料**：暖米色手工纸、照片印刷件、浆糊、纤维边。
- **工具与工序**：把照片印在纸上 → 沿手撕轮廓撕开 → 贴到纸面 → 四周延伸插画或留白。纤维边来自纸张被撕裂时拉出的纤维。
- **工艺痕迹**：手撕纤维边（不规则轮廓、窄纤维流苏、暖纸色露白）、浆糊渍、纸面颗粒与扫描噪点。
- **保真上限**：摄影锚点级。主体（照片部分）全保真，周围纸面可抽象。这是唯一"一部分照片、一部分纸"的工艺。
- **抽象倾向**：默认 2；范围 1-3。
- **色彩规则**：保持照片自然色；额外至多一个源图派生高纯色作结构（面积 2-15%）；墨色只用纸色 + 至多两个中性墨值。
- **文字与排版**：可手写 / 打字机 / 铅笔小字（≤5 英文词 / ≤8 汉字）；默认 no-text 亦可。
- **构图基因**：照片约 25-50%；纸面插画成大面积场但大部分留白；撕纸边界只出现在主要照片-纸交接处，不做四周等距装饰框。
- **质检项**：纤维边是否只出现在主要交接处（没有变成四周等距装饰框）？照片部分是否保持真实？有没有干净数字裁切或贴纸描边？
- **工艺参考图**：`assets/craft-samples/torn-paper.jpg`

**工艺语言片段**：
```
撕纸拼贴：暖米色纸面，手撕纤维边只出现在主要照片-纸交接处；插画以剪影/断续轮廓/稀疏网点印刷，共享源图轮廓；照片部分保持真实；额外一枚源图派生高纯色作结构；纸面颗粒与平扫纹理。
```

## 5. letterpress — 活字凸版

- **材料**：金属活字、铅版 / 聚合物版、油性墨、厚棉纸。
- **工具与工序**：排字 → 锁版 → 滚墨 → 凸版压印。压印在纸上留下凹痕。
- **工艺痕迹**：文字的压印凹痕、墨色边缘不均、文字轻微嵌进纸面、活字排版的间距气息。
- **保真上限**：中。主体以"版画化剪影 + 文字区"呈现，细部让位给文字与版式。
- **抽象倾向**：默认 2；范围 1-3。
- **色彩规则**：单色或双色（黑 / 纸色 / 一枚强调色）；禁止多色。
- **文字与排版**：默认 no-text（照片转换场景不添加文字）；若用户提供文案可加（≤5 英文词 / ≤8 汉字），越简洁越好；确定性文字不交给生成。
- **构图基因**：主体上方或下方留标题带；文字区与图像区明确分区；压印感（文字略嵌纸面）。
- **质检项**：主体保真是否足够（影像可识别）？压印凹痕质感是否在？是否只有单色/双色？有没有把主体当文字整行排掉？有文字时文字是否准确？
- **工艺参考图**：`assets/craft-samples/letterpress.jpg`

**工艺语言片段**：
```
活字凸版印刷：单色/双色油墨+纸色，油墨压印的凹痕与墨色边缘细微晕开，纸纤维压实；画面保留影像主体与构图，不加文字（默认 no-text，除非用户提供文案）。
```

## 6. risograph — 孔版速印

- **材料**：孔版母版、大豆油墨、复印纸。
- **工具与工序**：扫描制版 → 每色一张母版 → 依次进纸套印。套印必然错位，墨色有特殊荧光感。
- **工艺痕迹**：套印错位（重影）、粗网点、荧光 / 高饱和墨色、油墨刮痕、纸张进纸时的轻微歪斜。
- **保真上限**：中。主体以平涂 + 网点呈现，细部让位给色彩。
- **抽象倾向**：默认 2；范围 2-3。
- **色彩规则**：2-3 色（源图主色派生 + 一枚荧光点缀色）；平涂不渐变。
- **文字与排版**：可丝网式粗体小标题（≤5 英文词 / ≤8 汉字）；默认 no-text 亦可。
- **构图基因**：平涂色块 + 粗网点密度区分层级；错位作为工艺节奏（可夸张但克制）；主体色块与背景色块分色。
- **质检项**：错位是否克制且来自套印（不是随意偏移）？网点是否只出现在应出现的区域？是不是只有 2-3 色？
- **适用限制**：**有机复杂形状主体（花等）易被重绘**——套色硬边化时模型倾向把复杂形状改成装饰元素（视觉实测：花朵无法识别）。
- **工艺参考图**：`assets/craft-samples/risograph.jpg`

**工艺语言片段**：
```
孔版速印：2-3 色平涂不渐变，一枚荧光点缀色；套印错位与粗网点来自套印工序；网点密度区分层级；高饱和墨色；纸张进纸微斜。
```

## 7. silkscreen — 丝网版画

- **材料**：丝网版、刮板、水基 / 油基墨、纸或布。
- **工具与工序**：感光制版 → 刮墨刀刮印 → 逐色叠加。每色一版，错位与墨膜不均常见。
- **工艺痕迹**：高饱和平涂、粗网点（halftone）、墨膜边缘不均（刮板痕）、套印错位、色块硬边。
- **保真上限**：中。主体以高对比平涂块呈现，可保轮廓与色彩关系。
- **抽象倾向**：默认 2；范围 2-3。
- **色彩规则**：源图主色派生 2-4 色高饱和撞色，每色平涂不渐变；禁止柔和渐变。
- **文字与排版**：可粗体描边短标题（≤5 英文词 / ≤8 汉字）；默认 no-text 亦可。
- **构图基因**：主体高对比平涂块居中或偏移；网点密度与色块大小区分层级；背景可用波普式重复图案（来源图节奏派生）。
- **质检项**：是否每色平涂（无渐变）？网点是否克制？色数是否在 2-4？有没有出现水彩晕染（工艺互串）？
- **工艺参考图**：`assets/craft-samples/silkscreen.jpg`

**工艺语言片段**：
```
丝网版画：高饱和平涂 2-4 色撞色，每色平涂不渐变；粗网点与墨膜边缘不均来自刮印；色块大小与网点密度区分层级；硬边；丝网印刷颗粒。
```

## 8. paper-cut — 剪纸层叠

- **材料**：多层彩色纸（2-4 层）、刻刀 / 剪刀、垫板、胶。
- **工具与工序**：分层画稿 → 每层单独剪刻 → 逐层粘贴 → 层间留投影。投影深度由层间距决定。
- **工艺痕迹**：硬边剪纸轮廓、层间投影（纸片间的影子）、纸面纹理、边缘偶有刀痕毛刺。
- **保真上限**：中高。每层一张纸色，主体层保留识别。
- **抽象倾向**：默认 2；范围 1-3。
- **色彩规则**：从源图主色提取 2-4 层纸色（前景深 / 背景浅）；保持色相关系；禁止太多色层。
- **文字与排版**：可剪刻字标题（≤5 英文词 / ≤8 汉字）；默认 no-text 亦可。
- **构图基因**：前景最暗完整剪影层、中景主体层、背景最浅轮廓层；层间明显投影制造深度；每层形状源图派生。
- **质检项**：是不是只有 2-4 层？层间投影是否在（深度感）？前景层是否最暗？有没有变成逐片碎片堆叠？
- **适用限制**：**有机复杂形状主体（花/人群/毛发等）不适用**——镂空硬边化会破坏主体识别性（视觉实测：花朵主体完全丢失，具体描述无法救回）。
- **工艺参考图**：`assets/craft-samples/paper-cut.jpg`

**工艺语言片段**：
```
剪纸层叠：2-4 层彩色纸片层叠，硬边剪纸，层间投影制造立体纵深；前景最暗完整剪影、中景主体层、背景最浅轮廓层；每层纸色与形状源图派生；纸面纹理可见。
```

## 9. darkroom — 暗房银盐

- **材料**：银盐相纸、显影 / 定影液、放大机、暗房。
- **工具与工序**：底片放大 → 曝光 → 显影 → 停显 → 定影 → 水洗。反差与颗粒由显影时间与相纸型号决定。
- **工艺痕迹**：胶片颗粒、反差压暗部提亮部、轻微晕影（暗角）、显影不均的灰雾、纸边曝光。
- **保真上限**：**最高**。几乎全保真，风格只剩颗粒、反差、调色、裁剪。
- **抽象倾向**：默认 0；范围 0-1（银盐不做抽象，做影调）。
- **色彩规则**：黑白（可暖调 / 冷调 / 硒调）或保留照片自然色的"冲印色"；禁止荧光。
- **文字与排版**：可手写底片边注（≤5 英文词 / ≤8 汉字）；默认 no-text。
- **构图基因**：保留照片原构图为主；反差与颗粒制造主次（主体更实、背景更虚更暗）；暗角收拢视线。
- **质检项**：主体是否保真（这是全保真工艺，任何主体改动都算退回）？颗粒与反差是否自然（不是滤镜式加噪）？有没有出现插画笔触（工艺互串）？
- **工艺参考图**：`assets/craft-samples/darkroom.jpg`

**工艺语言片段**：
```
暗房银盐：银盐相纸，胶片颗粒与反差来自显影；黑白或自然冲印色；主体保持照片原构图与保真，背景可用反差与暗角收拢视线；显影不均的灰雾与纸边曝光；无插画笔触。
```

## 10. cyanotype — 蓝晒

- **材料**：铁盐感光液、蓝晒纸、负片 / 实物、日光或 UV 灯、清水。
- **工具与工序**：涂布感光液 → 阴干 → 负片覆盖 → 日光曝光 → 水洗显影。曝光越久蓝越深。
- **工艺痕迹**：普鲁士蓝（Prussian blue）单色、高光纸白、阴影深蓝、感光液涂布不均的边缘光晕、纸纤维纹理、蓝晒特有的蓝调渐变。
- **保真上限**：中高。摄影工艺，保主体轮廓与明暗关系（以蓝色阶呈现）。
- **抽象倾向**：默认 1；范围 0-2。
- **色彩规则**：单色普鲁士蓝 + 纸白；禁止其他色（这是蓝晒的识别特征）。
- **文字与排版**：可手写感光备注 / 边缘题字（≤5 英文词 / ≤8 汉字）；默认 no-text。
- **构图基因**：保留照片构图为主；明暗转为蓝色阶（暗部深蓝、亮部纸白）；曝光边缘的轻微光晕作画框；主体以蓝阶对比立起。
- **质检项**：是否只有蓝色（出现其他色即退回）？蓝色阶是否自然连续（不是贴色）？光晕是否克制？有没有出现银盐黑白（工艺互串）？
- **工艺参考图**：`assets/craft-samples/cyanotype.jpg`

**工艺语言片段**：
```
蓝晒：单色普鲁士蓝 + 纸白；明暗转为蓝色阶渐变；保留照片构图；暗部深蓝、高光纸白；感光涂布边缘的轻微光晕；纸纤维纹理；无其他色。
```

## 11. ink-wash — 水墨

- **材料**：宣纸 / 毛边纸、墨、毛笔、清水。
- **工具与工序**：皴擦点染、浓淡干湿随笔控制 → 墨分五色（焦浓重淡清）→ 留白即气。笔势决定结构，水决定晕染。
- **工艺痕迹**：笔触的干湿浓淡、宣纸渗化晕染、墨色层次（焦 / 浓 / 重 / 淡 / 清）、纸白留白、笔锋的起收。
- **保真上限**：中。以意象保留主体轮廓与空间关系，细节让位给笔意。
- **抽象倾向**：默认 2；范围 2-3。
- **色彩规则**：墨色为主（焦浓重淡清）；至多极少量赭 / 花青点缀；大量留白。
- **文字与排版**：可题款 / 印章（≤8 汉字 / 印章红）；默认可少量。
- **构图基因**：留白是主动的（气与呼吸）；主体以墨色对比立起；背景虚淡或全留白；笔势（皴 / 点 / 染）承担结构；边角构图（不居中）。
- **质检项**：墨色是否有浓淡干湿层次（不是平涂黑）？留白是否主动（不是未画完）？有没有出现水彩的彩色晕染（工艺互串）？笔势是否承担结构？
- **工艺参考图**：`assets/craft-samples/ink-wash.jpg`

**工艺语言片段**：
```
水墨：墨分五色（焦浓重淡清），笔触干湿浓淡；宣纸渗化晕染；主体以墨色对比立起、背景虚淡或留白；留白主动承担呼吸；笔势皴点染承担结构；至多极少量赭/花青点缀。
```

## 12. minimalist — 极简

> 特殊类：**现代设计风格，非印刷工艺**。极简源于 20 世纪现代设计运动（包豪斯 / 瑞士设计），本卡按工艺卡结构收录，因为它对应"只保留核心颜色与线条"的普遍需求。

- **材料**：无特定承印物；画面 = 少量核心色块 + 精简线条 + 留白。
- **工具与工序**：无工序痕迹——信息减法过程：去细节 → 保主体轮廓 → 凝练 2-4 种主色 → 留白。
- **工艺痕迹**：无痕（这是与所有印刷工艺的关键区别：画面干净、无纹理、无颗粒、无纸纹）。
- **保真上限**：中（剪影级）。保留主体轮廓与主色，去除细节与背景纹理。
- **抽象倾向**：默认 2；范围 1-3。
- **色彩规则**：限色（2-4 种核心色，色块均匀扁平、无渐变杂质）。**只写"从原图提取 2-4 种主色"，绝不指定具体色名**——实测指定"天蓝/塔白"会让模型执行字面色块、覆盖源图主色（主色命中 0.67→0.0）。
- **文字与排版**：无文字（no-text 模式）。
- **构图基因**：留白主导；主体轮廓完整居中或黄金分割；背景简化为纯色大块；线条流畅干净。
- **质检项**：主体轮廓是否仍可识别（边缘相关性 ≥0.6）？主色是否保留（与原图主色对比）？**背景是否合并为单一色块（top1 色占比 ≥0.5）**？是否干净无噪点无纸纹？
- **参数**：seedream 通道 reference_strength **甜点 0.7**（减法风格，实测与印刷工艺的 0.9 不同——0.9 会压住背景合并：单色化 0.348 vs 0.7 时的 0.677）。剪影型主体（日出山脉、月亮）可保持 0.9，复杂背景主体（树林、多元素场景）降到 0.7 或更低。
- **适用限制**：**纹理密集主体（浪、树叶、人群、发丝）保真上限过低，慎用**——实测海浪极简三轮均丢失主体（边缘相关性 0.19-0.29），此类主体应路由到其他工艺。
- **工艺参考图**：`assets/craft-samples/minimalist.jpg`

**工艺语言片段**：
```
极简：去除一切非核心细节，只保留主体轮廓与核心色彩；从原图提取 2-4 种克制的色块和少量干净流畅线条构成画面，背景合并为单一纯色平涂或大面积留白；色彩均匀扁平，无纹理、无噪点、无渐变杂质。
```
