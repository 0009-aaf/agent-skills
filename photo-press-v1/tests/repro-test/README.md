## 执行日志（木刻）

**三问读图**：是什么——黄昏逆光剪影的黑白横条纹灯塔立于画面右侧，极低地平线、天空占 2/3、前景崖顶步道人物剪影；为什么值得——人造光（灯塔航标灯/路灯）穿透暮色黑暗的对比；怎么做——木刻大块黑白正适合剪影主体。
**保护清单**：PRESERVE=灯塔条纹塔身+航标灯、位置右侧、高约 2/3、极低地平线、逆光剪影、紫粉渐变天空。
**双旋钮**：保真 3 紧、抽象 2（稠密细节合并为大形+刀痕）。
**参数**：refs=[源图, woodcut.jpg]，strength 0.9（文档实测甜点）。
**提示词**：8 模块编译，中文直白保真锚定前置、木刻 3-5 痕迹词、2 条否定。
**返检**：首轮 4/5（柔边渐变混入）→ 定向修正只改硬避免模块、重复 PRESERVE → 重跑仍残留 → 按文档如实告知局限。
**新发现已写回工艺卡**：木刻对"渐变天空"（黄昏紫粉/暮色）场景有柔边渐变残留的系统性倾向。

## 执行日志（水彩）

**三问读图**：是什么——日出俯瞰层叠山峦雾中森林、太阳在远山脊线上方左侧、低角度逆光；为什么值得——光穿过层叠雾气的冷暖对比；怎么做——水彩晕染正适合雾与晨光。
**保护清单**：PRESERVE=太阳位置与形态、层叠山峦纵向层次、低角度逆光、暖橙粉天空。
**双旋钮**：保真 2 标准、抽象 1。
**参数**：refs=[源图, watercolor.jpg]，strength 0.9。
**返检**：首轮 3/4（主体最实 fail）→ 定向修正只改分层模块（中景山峦最实、前景背景弱化）→ 重跑全 pass。

## 通道能力检查探针验证

同一提示词，带参考 vs 不带参考各生成一张（`probe`）：
- 带参考保留源图构图（太阳位置、层叠山峦、前景草甸）：yes
- 不带参考自由生成、与带参考结构完全不同：yes
- **判定：reference_used=yes，检测逻辑有效**（"两张几乎相同=参考被忽略"的判据可正确区分支持/忽略参考）。已写回 SKILL.md 第七步。
